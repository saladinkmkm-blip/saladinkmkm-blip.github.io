  • 업체 초대와 제출된 계획서 확인

Before You Start

작성 전에 준비해주세요

  • 초대 링크담당 관리자가 전달한 업체별 링크
  • 업체·작업 정보담당자, 작업 장소, 일정과 작업 범위
  • 인원·장비작업에 참여하는 인원과 사용하는 장비
  • 작업 순서·안전대책작업 단계별 위험요인과 예방조치

Help

처음 이용하시나요?

작업허가는 어디에서 작성하나요?

온라인 서비스 연결 후 이 영역의 작성 버튼에서 시작합니다. 협력업체는 관리자가 전달한 초대 링크가 필요합니다. 현재 온라인 작성은 준비 중입니다.

초대 링크를 받지 못했어요.

작업을 요청한 담당 관리자에게 업체명과 작업 내용을 알려주고 초대 링크를 요청해주세요.

계획서를 제출하면 바로 작업해도 되나요?

제출 후 관리자 검토가 필요합니다. 계획서 승인과 별도로 현장 확인 및 작업허가가 완료되어야 작업을 시작할 수 있습니다.

Service Map

사업장 안전관리를 위한 핵심 서비스

업무를 빠르게 이해할 수 있도록 6개 영역으로 구분했습니다. 각 카드는 실제 서비스 등록 시 상세 페이지로 확장하기 좋은 구조입니다.

01

위험성 평가

공정, 설비, 작업절차의 위험요인을 발굴하고 개선 우선순위와 실행 계획을 정리합니다.

02

안전보건관리체계

목표, 책임, 점검, 개선 활동이 반복되도록 사업장 맞춤형 관리 체계를 설계합니다.

03

산업안전 교육

관리감독자, 신규 근로자, 위험작업자를 대상으로 실무 중심 교육 흐름을 제공합니다.

04

건설현장 점검

추락, 낙하, 장비, 임시시설물 등 고위험 항목을 중심으로 현장 개선안을 도출합니다.

05

화학물질·환경 안전

취급 물질, 보관 기준, 비상대응, 표시 체계를 점검하고 관리자료로 정리합니다.

06

안전자료 구축

업종별 체크리스트, 교육자료, 사고 예방 가이드를 찾기 쉬운 자료실로 구성합니다.

Education

대상별 안전교육 프로그램

5개 과정을 2-3 배열로 배치해 비대칭 빈칸 없이 안정적인 시선을 만들었습니다. 모든 과정명과 시간은 홈페이지 예시 데이터입니다.

Consulting Flow

문의부터 개선관리까지 명확한 5단계

처음 방문한 담당자도 다음 행동을 바로 알 수 있도록 상담 흐름을 단순하고 선명하게 정리했습니다.

01

상담 접수

업종, 인원, 현장 위치, 관심 서비스를 입력합니다.

02

현황 확인

작업공정, 위험작업, 교육 대상자를 확인합니다.

03

계획 수립

교육, 점검, 자료 제공 범위와 일정을 정리합니다.

04

실행

현장 확인, 교육 운영, 체크리스트 배포를 진행합니다.

05

개선 관리

개선 이력과 재점검 계획을 남깁니다.
